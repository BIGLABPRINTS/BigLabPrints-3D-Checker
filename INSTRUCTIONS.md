#BigLabPrints 3D Checker – Instructions#

Usage

The BigLabPrints 3D Checker can be used directly as an HTML file on a computer.

1. Download the HTML file

Download the index.html file from this repository.

2. Open the file

After downloading, you can open the file on your computer.

Simply double-click the index.html file.

It will then open in your default web browser.

Alternatively, you can right-click the file, select “Open with”, and then choose a browser such as Chrome, Edge, Firefox, or Safari.

3. Use the Checker

After opening the file in your browser, you can use the BigLabPrints 3D Checker normally.

An internet connection is not necessarily required for basic use of the downloaded HTML file, provided that all required content is already included in the file.
